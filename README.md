## 🚀 代表项目与实践

这里展示了我从需求洞察到 AI 产品落地的部分独立实践：

### 1. 英语口语陪练与 AI 机制设计 (`english-practice`)
*   **项目简介**：针对语言学习痛点的 AI 练习工具。设计了“破冰-评估-场景对话-复盘”的完整学习闭环。
*   **产品思考**：深度探索了 AI 交互时的**四象限纠错判定机制**。语言学习的核心是“低压力的有效输出”，通过设计场景锚点与 recast 机制，让 AI 在提供正确输入的同时，保护用户的学习自信心。
*   🔗 **[查看 README 文档 & 代码](./english-practice)**

### 2. 幼儿园英文教案生成器 (`eplan`)
*   **项目简介**：面向一线幼师的 B 端教研提效工具。支持按小/中/大班切换，一键生成符合儿童认知特点的差异化英文教案，包含全英文教师逐字稿及 PPT 导出功能。
*   **产品思考**：教研工具的核心是“极致的提效”。通过拆解备课的底层流程，用 AI 将碎片化的大纲转化为结构化、可复用的教案，直接减少教师的机械性工作。
*   🔗 **[查看 README 文档 & 代码](./e-plan)**

### 3. 对话式人格探索向导 (`mbti-deeper`)
*   **项目简介**：基于大模型对话的深度探索工具。经历了 V1 到 V4 的四次迭代，通过多轮对话引导用户探索人格倾向。
*   **产品思考**：从“做测试”到“做体验”。迭代的核心在于**“约束大模型的对话边界”**与**“降低用户认知负荷”**，让 AI 在不跑题的前提下，提供有温度、深度的反馈。
*   🔗 **[查看 README 文档 & 代码](./mbti-deeper-v4)**

### 4. 英国硕士 DIY 选校导航 & Offer 后指南 (`after-offer-in-uk`)
*   **项目简介**：针对英国留学细分场景提供全流程内容导航与实用指南。
*   **产品思考**：针对复杂的申请场景，核心是“信息结构化与路径导航”。把碎片化信息整合成清晰的阶段，降低用户的认知门槛。
*   🔗 **[查看 README 文档 & 代码](./after-offer-in-uk)**

## 🧠 我的产品方法论

*   **底层错因拆解**：能从词汇、语法结构、时态等维度精准定位学生薄弱点，输出个性化提升方案，用教研深度驱动产品设计。
*   **AI 落地实践**：独立搭建过 AI Agent，能通过 Prompt 调优与规则约束，将 AI 能力深度融入真实教学场景，避免大模型“瞎编”。
*   **教研与闭环设计**：熟悉 K12 认知规律与家长诉求，擅长将教学目标转化为游戏化、互动式的完整学习闭环，提升学习留存。
*   **全链路交付**：具备从需求调研、PRD 撰写到协同研发上线的完整项目管理经验，曾在 1 个月内推动停滞项目重新上线。
