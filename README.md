## 代表项目

### 1. mbti-deeper · 人格探索向导

MBTI 人格测试工具的迭代版本展示。通过多轮对话帮助用户探索人格类型倾向并获得个性化发展建议。项目经历了 V1（初始版）到 V4（优化版）四次完整迭代，逐步完善了 **场景化提问、混合态解析、防带偏机制、"被看见"高光时刻** 等核心产品机制。

**产品思考**：从"做测试"到"做体验"——每次迭代都围绕用户心理模型做减法，降低认知负荷，让用户在对话中自然"被看见"。

### 2. english-practice · 英语口语陪练

模拟聊天界面的英语口语练习工具。设计了"打招呼 → 前置测试 → 评估 → 场景对话 → 复盘"五阶段学习路径，支持语音输入和对话记忆系统，根据用户水平（起步/基础/进阶）动态调整对话难度。

**产品思考**：语言学习的核心痛点是"不敢开口"——通过降低首次使用门槛（打招呼破冰）、即时正反馈（发音纠正+鼓励）、个性化路径（水平评估后定制内容）来解决。

- **代码仓库**：[点击查看源码](这里替换为 mbti-deeper 文件夹的 GitHub 链接)

### 3. ai-partner · AI 陪伴社交应用

移动端优先的 AI 陪伴社交平台。设计了 Luna（温柔陪伴型）、Kai（直接行动型）、叶叶（温暖长辈型）三个差异化角色，实现发帖动态、私信聊天、情绪关键词识别与权重推荐算法等核心功能。

**产品思考**：AI 产品的核心不是技术炫技，而是让用户感受到"被理解"——通过情绪识别 + 角色差异化人设 + 权重推荐，让每个用户都能找到适合自己的陪伴对象。

### 4. eplan · 幼儿园英文教案生成器

幼儿园英文教案一键生成工具。支持按小班/中班/大班切换生成差异化教案，内置 PPT 导出功能，包含全英文教师稿件，帮助幼师快速完成备课流程。

**产品思考**：ToB/ToE 产品的核心是"省时间"——幼师备课时间宝贵，工具必须做到"输入最少、输出最全"，一键生成 + PPT 导出覆盖从构思到上课的完整链路。

## 产品方法论

- **用户洞察**：擅长通过用户访谈、数据分析等手段挖掘真实需求，避免"自嗨式"产品决策
- **MVP 迭代思维**：快速推出最小可用版本，根据用户反馈持续迭代优化，用小成本验证大假设
- **数据驱动决策**：关注核心指标变化（完成率、留存、NPS），用数据指导产品方向调整
- **全链路能力**：从需求分析、交互设计到开发上线，具备产品全生命周期管理经验
